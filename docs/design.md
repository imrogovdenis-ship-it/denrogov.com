# Принципы дизайна: Личный сайт denrogov.com

Срез: 2026-10-01 UTC. Статус: документационный кандидат для review; не production-релиз.

Сохранить композицию, оригинальные изображения и Tilda-поведение. Переключатель языка — реальные ссылки, без автоматического редиректа по браузеру. Китайский: `/zh/`, `zh-Hans`; canonical/hreflang должны быть взаимными.

Блок аудитории — компактный итог перед прессой, а не все внутренние измерения. Сумма подписок не равна уникальным людям. Неподтвержденные/null метрики не показывать как ноль. Исторические словари и owner overrides — часть воспроизводимости, не публичная контентная страница.
