# Архитектура: Личный сайт denrogov.com

Срез: 2026-10-01 UTC. Статус: документационный кандидат для review; не production-релиз.

Сайт — статический экспорт с отдельным поддерживаемым слоем. В актуальном remote есть `deployed-public/` для согласованного публичного дерева и `maintenance/` для генераторов, переводов и проверок. Корневые Tilda-файлы и build-only материалы нельзя считать одним deploy root.

Audience generator строит блок аудитории поверх зафиксированного baseline. I18n хранит registry, routes, dictionaries и templates. Русский/испанский baseline и новые английский/китайский слои имеют разные режимы сохранения. Не запускать старый импорт переводов поверх измененных словарей.
