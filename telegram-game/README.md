# Portal Flight — игра-виджет для бота @portalvr

Аркада «тапай, чтобы лететь» прямо в сообщении бота (HTML-виджет Telegram Bot API 10.4):
топ-10, личное место каждого игрока, коэффициенты за друзей и подписку на @portal_vr_news.

Дизайн: `docs/superpowers/specs/2026-11-11-telegram-game-widget-design.md`.

## Как запустить (один раз)

Бот уже развёрнут как функция `portal-game` в проекте Supabase `oxsmllzxalxriiwgwpna`,
таблицы созданы. Осталось дать ему токен.

1. **Возьмите токен бота.** В Telegram: @BotFather → `/mybots` → @portalvr → API Token.
   Токен никому не отправляйте и не кладите в репозиторий.
2. **Положите токен в секреты Supabase.** Откройте
   <https://supabase.com/dashboard/project/oxsmllzxalxriiwgwpna/functions/secrets>
   и добавьте секрет с именем `BOT_TOKEN` и значением-токеном.
3. **Сделайте @portalvr администратором канала @portal_vr_news** (достаточно минимальных прав).
   Без этого Telegram не даёт боту проверять подписку, и бонус за неё не начисляется.
4. **Проверьте, что функция жива.** Откройте в браузере
   <https://oxsmllzxalxriiwgwpna.supabase.co/functions/v1/portal-game>.
   Должна быть строка вида `portal-game f67ee029b9d9 ok`. Если в ней слово `CORRUPT` —
   код игры повредился при выкладке, функцию нужно выложить заново (см. ниже).
5. **Подключите бота.** Откройте
   <https://oxsmllzxalxriiwgwpna.supabase.co/functions/v1/portal-game/setup>.
   Страница ответит, что вебхук установлен, и скажет, видит ли бот канал как администратор.
   Если написано, что `BOT_TOKEN` не задан, подождите минуту после шага 2 и обновите страницу.
6. **Напишите боту `/start`** — придёт сообщение с игрой.

Отдельный «секрет вебхука» задавать не нужно: функция сама выводит его из токена бота и
сообщает Telegram на шаге 5. После смены токена в @BotFather повторите шаги 2 и 5.

## Как это устроено

- `widget/game.js` — физика и счёт, без DOM. `widget/widget.html` — экран, кнопки, общение с ботом.
- `build/build.mjs` — собирает один HTML, минифицирует и проверяет лимиты Telegram
  (32 768 байт и 4096 байт после zlib-9). При превышении сборка падает.
- `supabase/functions/portal-game/` — вебхук. `core.ts` — вся логика (рейтинг, коэффициенты,
  проверка правдоподобия очков), `handler.ts` — HTTP и проверка подписи Telegram,
  `store.ts` — база, `tg.ts` — Bot API, `widget.generated.ts` — собранная игра (генерируется).
- `supabase/migrations/` — таблицы `flap_players`, `flap_runs`, `flap_config` и SQL-функции.
  RLS включён без политик: доступ есть только у функции.

Запросы виджета к боту: `i` — состояние игрока, `s` — начало забега, `e:<очки>` — результат.
Итог = очки × коэффициент; коэффициент = 1 + 0.1 за подписку + 0.1 за каждого друга (до 15).

## Разработка

```bash
cd telegram-game
npm install
npm test        # собирает виджет и гоняет все тесты, включая прогон в браузере
npm run build   # только сборка; печатает размер
```

`dist/widget.html` можно открыть в обычном браузере: вне Telegram игра работает без рейтинга.

## Как выпустить новую версию игры

1. Измените файлы в `widget/`, выполните `npm test`.
2. Выложите функцию заново из папки `telegram-game/`:
   `supabase functions deploy portal-game --no-verify-jwt --project-ref oxsmllzxalxriiwgwpna`
3. Откройте ссылку из шага 4 выше и убедитесь, что в конце строки `ok`.

Код уже отправленного виджета Telegram не меняет: старые сообщения остаются со старой игрой
и перестают получать обновления топ-10. Новую версию игрок получает по `/start`.

## Если кто-то накрутил результат

Очки присылает сам виджет, поэтому бот отсекает только невозможные результаты
(больше ворот, чем можно пролететь за время забега). Удалить игрока можно в SQL-редакторе Supabase:

```sql
delete from flap_players where user_id = 123456789;
```

Топ-10 пересоберётся, когда любой игрок пришлёт следующий результат.

## Ограничения Telegram, о которых стоит знать

- В продакшене виджеты работают только в личном чате с ботом; их нельзя переслать или отправить в канал.
- Звука и ввода текста в виджетах нет.
- В настоящем Telegram игра автоматически не тестировалась: проверены логика, сборка и работа
  в браузере с имитацией Telegram. Первый запуск по шагам выше — и есть боевая проверка.
